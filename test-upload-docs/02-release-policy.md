# Release Policy

## Purpose

This sample policy is used to test Markdown uploads, headings, lists, and inline formatting.

## Rules

1. Every release must have a named owner.
2. A reviewer must inspect the proposed change before publication.
3. Published versions are immutable.

> This is sample content only. It contains no real operational policy.

### Checklist

- [x] Confirm the change summary
- [ ] Assign a reviewer
- [ ] Record the publication note
