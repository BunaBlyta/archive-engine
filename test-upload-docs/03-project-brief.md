# Northstar Project Brief

**Status:** Draft  
**Owner:** Sample Team  
**Target date:** 2026-09-15

## Summary

Northstar is a fictional effort to make document review easier for small teams. The first milestone is a dependable upload, version, and approval flow.

## Success measures

- A new document can be uploaded in under one minute.
- Reviewers can see exactly what changed.
- Each published version has a visible author and timestamp.

## Risks

The biggest risk is confusing an archived document with an active one. The interface should make state and ownership obvious.
